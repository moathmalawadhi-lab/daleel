# دليل 📚

دليل تفاعلي يساعد زوار **معرض الكويت الدولي للكتاب** يوصلون لأي مكتبة بسهولة.

**الرابط:** https://moathmalawadhi-lab.github.io/daleel/

- بحث يتحمّل الأخطاء الإملائية (باسم المكتبة أو رقم الجناح أو الدولة)
- البحث حسب الاهتمام: أطفال، أدب وروايات، كتب إسلامية، قانون، دراسات، كتب إنجليزية، جهات ومؤسسات، فنون (تصنيف تقريبي من الأسماء)
- خرائط مرسومة للقاعات (5، 6، 7، وصالة كتاب الطفل) مع تحديد الجناح وجيرانه
- «ودّني لها»: طريق مشي مرسوم بين الممرات مع مسافة ووقت تقريبي
- «قائمة كتبي»: الكتب اللي تبي تشتريها، مربوطة بمكتباتها، مع ملاحظات لكل مكتبة
- قائمة زيارتي وجولة مرتّبة من الأقرب للأقرب، ومشاركة القائمة برابط
- تشتغل بدون نت بعد أول فتح، وتنضاف لشاشة الجوال
- تكبير الخط، وضوح عالي، وقراءة المكان بالصوت — مناسبة لكل الأعمار

البيانات منقولة من مخططات وقوائم الأجنحة المعلنة للمعرض، وقد تتغيّر بعض الأجنحة أثناء المعرض.
