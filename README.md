# وين الدار؟ 📚

دليل تفاعلي يساعد زوار **معرض الكويت الدولي للكتاب** يوصلون لأي دار نشر أو مكتبة بسهولة.

- بحث يتحمّل الأخطاء الإملائية (بالاسم أو رقم الجناح أو الدولة)
- خرائط مرسومة للقاعات (5، 6، 7، وصالة كتاب الطفل) مع تحديد الجناح وجيرانه
- قائمة زيارتي وجولة مرتّبة من الأقرب للأقرب
- تكبير الخط، وضوح عالي، وقراءة المكان بالصوت — مناسبة لكل الأعمار

البيانات منقولة من مخططات وقوائم الأجنحة المعلنة للمعرض، وقد تتغيّر بعض الأجنحة أثناء المعرض.
